# Market Smart CRM & Sales Database Project

## 📌 نبذة عن المشروع
مشروع تحليلي لإدارة قواعد بيانات المبيعات والعملاء، مصمم خصيصاً لمحاكاة متطلبات سوق العمل التجاري، يعتمد على استعلامات SQL متقدمة لاستخراج التقارير، إدارة المخزون، وتحليل سلوك العملاء.

## 🛠 التقنيات المستخدمة
- Relational Database (SQL)
- Aggregate & Numeric Functions
- String Manipulation
- Data Filtering & Joins

## 📁 محتويات المشروع
- `database_schema.sql`: ملف بناء الجداول والعلاقات الأساسية.
- `market_queries.sql`: ملف الاستعلامات والتقارير السوقية والتحليلية.
